1. Principes généraux

Le système de permissions des Archives repose sur trois piliers :

🎭 Rôles — Chaque utilisateur peut avoir un ou plusieurs rôles (ex : Sous-officier + Sanitat). Les rôles déterminent ce que l'utilisateur peut voir et faire.
📋 Salons — Chaque action du site est un « salon » avec sa propre permission. Par exemple, rapports.create = droit de créer un rapport, medical.visites.edit = droit de modifier une visite médicale.
🔗 Combinaisons — Certaines actions nécessitent d'avoir plusieurs rôles simultanément. Par exemple, créer une visite médicale requiert d'être à la fois Sous-officier ET Sanitat.
⚠️ Règle d'or : Le rôle 👑 Administration contourne toutes les permissions. Un administrateur peut tout faire, toujours.

Il existe deux types de rôles :

Rôles personnalisés

Les officiers et administrateurs peuvent créer des rôles personnalisés pour des besoins spécifiques. Un rôle personnalisé ne peut pas être de niveau supérieur à celui de son créateur.

3. Hiérarchie des rôles

Le niveau d'un rôle détermine sa place dans la hiérarchie. Plus le nombre est bas, plus le rôle est élevé :

Niveau 0  │  👑 Administration / 🦅 Kommandeur der 7e Armee
Niveau 1  │  ⭐ Etat-Major
Niveau 2  │  🎖️ Officier / ⚔️ Kommandeur (régiment)
Niveau 3  │  📋 Administratif / 🗡️ Kommandeur Adjoint / 🔗 Officier Référent
Niveau 4  │  🛡️ Feldgendarmerie
Niveau 5  │  🪖 Sous-officier / 🏥 Sanitat
Niveau 7  │  👤 Militaire du rang
Niveau 99 │  👁️ Invité
Règle de hiérarchie : Un utilisateur ne peut pas attribuer un rôle de niveau supérieur ou égal au sien. Seul un administrateur peut attribuer le rôle Administration.

4. Les permissions par salon

Chaque fonctionnalité du site est découpée en « salons » granulaires. Un salon = une action précise.

Exemple : Section Médicale

🏥 Visites — Voir
🏥 Visites — Créer
🏥 Visites — Modifier
🏥 Visites — Valider
🏥 Visites — Signer
🏥 Visites — Supprimer
💊 Soins — Voir
💊 Soins — Créer
🏨 Hospit. — Voir
🏨 Hospit. — Créer
💉 Vaccins — Voir
💉 Vaccins — Créer
🩹 Blessures — Voir
🩹 Blessures — Créer
📊 Stats médicales

Chaque rôle a des permissions par défaut sur ces salons. L'administrateur peut les ajuster depuis l'onglet 🔐 Rôles & Permissions.

Comment lire les permissions

✅ Voir = L'utilisateur a accès à cette action

○ Non coché = L'utilisateur n'a pas accès

Les permissions s'additionnent entre les rôles. Si un utilisateur a les rôles Sous-officier + Sanitat, il cumule les permissions des deux.

5. Permissions combinées (ET)

Certaines actions sensibles nécessitent d'avoir plusieurs rôles en même temps.

Exemple concret : Pour créer une visite médicale, il faut être :
🪖 Sous-officier + 🏥 Sanitat

Un Sanitat seul ne peut pas créer de visite. Un Sous-officier seul non plus. Il faut les deux.

Configurer une permission combinée

  1. Aller dans Administration → 🔐 Rôles & Permissions
  2. Descendre jusqu'à la section 🔗 Permissions combinées
  3. Sélectionner le salon concerné dans le menu déroulant (ex : Visites médicales › Créer)
  4. Cocher les rôles requis (minimum 2)
  5. Cliquer sur Ajouter
💡 Astuce : Les permissions combinées sont appliquées en temps réel (cache de 60 secondes). Pas besoin de redémarrer quoi que ce soit.

6. Gérer les rôles

Modifier les permissions d'un rôle

  1. Aller dans Administration → 🔐 Rôles & Permissions
  2. Cliquer sur le rôle dans la liste de gauche
  3. Cliquer sur ✏️ Modifier
  4. Les permissions sont groupées par section (Effectifs, Rapports, Médical, etc.). Cliquer sur une section pour la dérouler.
  5. Cliquer sur un salon pour activer (✅) ou désactiver (○) la permission
  6. Utiliser ✅ Tout ou ❌ Rien pour configurer rapidement une section entière
  7. Cliquer sur 💾 Sauvegarder

Créer un rôle personnalisé

  1. Cliquer sur ✨ Nouveau rôle
  2. Renseigner le nom, la couleur et le niveau
  3. Configurer les permissions par salon
  4. Sauvegarder
⚠️ Les rôles système (Administration, Etat-Major, etc.) ne peuvent pas être supprimés. Leurs permissions peuvent être ajustées, mais leur nom et leur statut sont protégés.

7. Assigner un rôle à un utilisateur

  1. Aller dans Administration → 👥 Utilisateurs
  2. Cliquer sur l'utilisateur
  3. Dans la section 🔐 Rôles, cliquer sur un rôle pour l'activer (✅) ou le désactiver (○)
  4. Le changement est immédiat — pas besoin de sauvegarder
Un utilisateur peut avoir plusieurs rôles. Ses permissions sont le cumul de tous ses rôles. Par exemple, un utilisateur avec Sous-officier + Sanitat aura toutes les permissions des deux rôles.

Kommandeur — Toutes les permissions sur son régiment, y compris transferts, renvois, suppressions et administration du régiment.
Kommandeur Adjoint — Mêmes permissions que le Kommandeur, sauf la suppression d'effectifs et certaines actions administratives.
🔗 Officier Référent — Officier rattaché au régiment d'un effectif. Permissions de niveau officier, scopées au régiment.

9. Rôle Invité

Le rôle 👁️ Invité est automatiquement attribué aux utilisateurs qui n'ont aucun autre rôle.

Permissions Invité : Lecture seule sur les effectifs, soldbuch, rapports, documentation, journal, front, organigramme, archives et recherche. Aucune permission de création, modification ou suppression.

10. Questions fréquentes

Un utilisateur ne peut pas accéder à une page — pourquoi ?

Vérifiez ses rôles dans Administration → Utilisateurs. S'il n'a que le rôle Invité ou Militaire du rang, il n'a probablement pas les permissions nécessaires. Assignez-lui le rôle approprié.

J'ai configuré une permission combinée mais ça ne marche pas

Les permissions combinées ont un cache de 60 secondes. Attendez une minute et réessayez. Vérifiez aussi que l'utilisateur possède bien tous les rôles requis (pas juste un seul).

Comment retirer tous les accès à un utilisateur ?

Deux options :
• Désactiver le compte — L'utilisateur ne peut plus se connecter
• Renvoyer l'effectif — Via le bouton 🚪 Renvoyer dans la fiche effectif ou l'onglet Régiment

Quelle différence entre « Permission insuffisante » et « Cette action nécessite les rôles X + Y » ?

• Permission insuffisante = L'utilisateur n'a pas du tout la permission salon
• Nécessite les rôles X + Y = L'utilisateur a la permission salon, mais il lui manque un des rôles requis par la permission combinée
