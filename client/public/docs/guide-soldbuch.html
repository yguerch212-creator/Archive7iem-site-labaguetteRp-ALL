📖 Comment remplir son Soldbuch

Sanitätsdienst — 7. Armeekorps — Guide pratique

Le Soldbuch (livret de solde) est le document d'identité militaire de chaque soldat. Il contient toutes les informations personnelles, administratives et médicales. Ce guide explique chaque section, qui la remplit, et quoi y mettre.

🏷️ Légende — Qui remplit quoi ?

👤 SOLDAT ⭐ OFFICIER / ADMINISTRATIF 🏥 SANITÄTS ⚙️ AUTOMATIQUE 🔧 ADMIN

Quand vous remplissez votre propre Soldbuch, les modifications sont enregistrées directement. Si un administratif remplit le Soldbuch d'un autre soldat, le propriétaire reçoit une notification et doit valider les informations avant qu'elles soient confirmées. Les admins peuvent modifier n'importe quel Soldbuch sans validation.

📄 Page 3 — Attestations

⭐ OFFICIER ⚙️ AUTO

Chaque modification aux pages 1 et 2 est enregistrée ici. Les attestations sont générées automatiquement lors de :

  • Promotion — changement de grade
  • Décoration — attribution d'une médaille
  • Modification de données — changement validé sur les pages 1-2

Un officier peut aussi ajouter des attestations manuelles et les signer. Il peut également barrer une attestation (rayée avec motif, visible mais invalide) ou la supprimer (admin uniquement).

Demandes d'habillement

Un soldat peut soumettre une demande d'habillement depuis le module dédié (page « Habillement »). L'officier approuve ou refuse la demande. Si approuvée, une attestation automatique est créée en page 3 du Soldbuch.

✍️ Les signatures

Il y a deux emplacements de signature sur le Soldbuch :

  1. Signature du détenteur (page 2, bas) — Le soldat signe son propre Soldbuch. Dessinez votre signature au clic.
  2. Signature officier référent (page 2, bas) — Un officier ou administratif valide le Soldbuch en signant.

Les attestations (page 3) peuvent aussi être signées individuellement par un officier.

💡 Votre signature est enregistrée et réutilisable sur d'autres documents du site (rapports, affaires, visites médicales...). Dessinez-la soigneusement !

🎲 Les numéros de série

Certains champs ont un bouton 🎲 qui génère automatiquement un numéro au format UNITE-ANNEE-XXXX (ex: 916-2026-4817). Utilisez-le pour l'équipement, les registres, etc.

📱 Compatibilité mobile

Le Soldbuch est consultable sur mobile (lecture seule). Pour modifier le contenu (cellules éditables, layout), utilisez un ordinateur. Les boutons d'édition sont masqués sur mobile.
