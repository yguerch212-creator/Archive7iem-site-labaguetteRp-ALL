# Règlement Combat — LaBaguetteRP (contexte pour analyse IA)

## Avant-postes (VP) — Falaise/Linéaire
- Attaquer un VP : 3 joueurs min avec un sous-officier ou CPL/Gef
- 10 minutes entre chaque VP
- Prises dans l'ordre : VP1 → VP2 → VP3 → VP4 → VP5
- VP5 : 2 assauts max sans renfort
- 2 assauts sans renfort OU 1 assaut + 1 vague de renfort par VP
- Assaut repoussé = annonce en /advert
- Si ennemi a VP1 : 15 min de prépa entre assauts
- Si victoire attaque de base : retour VP-1
- Dernier VP perdu : 2 assauts pour reprendre, sinon attaque de base possible

## Avant-postes — Berlin (non-linéaire)
- 2 zones : Campagne (US) et Ville (ALL)
- Zone Ville : Kommandantur + Checkpoint
- Zone Campagne : Village + Poste Radio
- VP1 (Feldkommandantur) + VP2 (Marais) = zone ALL
- VP4 (Village) + VP5 (Poste Radio) = zone US
- VP3 (Mur Est / Porte Est) = checkpoint obligatoire
- Posséder ses 2 VP → peut attaquer Porte Est (VP3)
- Posséder VP3 → peut attaquer zone ennemie
- Contrôler 2 VP ennemis + tenir 15 min → attaque de base possible
- 5 min entre captures dans même zone
- 10 min après capture VP3 avant attaquer zone ennemie
- Tanks = zones bleues uniquement sauf déplacement

## Assaut de base
- Minimum 10 joueurs
- Autorisation staff requise
- 15 minutes pour l'assaut
- Cérémonie post-attaque : 20 min max

## Types d'événements dans le système
- **prise** : capture d'un VP (annoncé en /advert)
- **perte** : perte d'un VP (ennemi fait /advert prise)
- **attaque** : assaut de base (win ALL = défense réussie côté ALL, win US = base ALL prise)
- **defense** : défense de base (win ALL = base défendue, win US = base perdue)
- **debut** : début des combats de la session
- **fin** : fin des combats / cessez-le-feu

## Métriques clés pour l'analyse
- Win rate batailles = (victoires ALL) / (total batailles)
- VP net = prises - pertes (positif = avancée territoriale)
- Temps de tenue VP = durée entre prise et perte
- Ratio offensif/défensif = nb attaques / nb défenses
- Performance par créneau horaire
- Berlin : progression VP1+VP2 → VP3 → VP4/VP5 (non-linéaire)
